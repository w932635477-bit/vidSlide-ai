🎯 何时需要下载？

VidSlide AI 通过以下规则判断是否需要下载外部图片：

  • 本地结果不足：预置库和缓存库结果少于2个
  • 质量不佳：本地素材平均匹配度低于0.6
  • 用户偏好：用户明确要求外部搜索
  • 调度器推荐：AI分析认为需要外部补充
💾 何时缓存下载？

下载的图片并非全部缓存，只有满足条件才会被本地存储：

  • 百度图片：一律缓存（国内用户优先）
  • 高频使用：使用次数超过5次的素材
  • 存储空间：当前缓存未超过500MB限制
  • 平台优先级：Unsplash及以上优先级平台
🧹 缓存清理策略

当存储空间紧张时，采用LRU（最近最少使用）策略清理：

  • 访问时间：最少使用的素材优先清理
  • 使用频率：低频素材优先清理
  • 平台优先级：低优先级平台素材优先清理
  • 自动清理：每小时检查，超过80%自动清理
🎨 质量评估标准

对图片进行多维度质量评估：

  • 分辨率：4K+ (20M像素) 得25分
  • 受欢迎度：点赞>1000得15分
  • 下载量：下载>1万得10分
  • 标签完整：标签>5个得5分
  • 描述完善：有详细描述得5分
质量评分算法：
基础分50 + 各维度得分，总分0-100分
高质量素材（>75分）优先缓存

// 缓存决策算法
shouldCache(material, source, options = {}) {
  // 1. 平台优先级：百度图片一律缓存
  if (source === 'baidu') {
    return true
  }

  // 2. 存储空间检查：不能超过500MB
  const materialSize = this.estimateMaterialSize(material)
  if (this.currentCacheSize + materialSize > this.maxCacheSize) {
    return false
  }

  // 3. 使用频率：高频素材优先缓存
  const usageCount = this.usageCount.get(material.id) || 0
  if (usageCount > 5) {
    return true
  }

  // 4. 平台优先级：只缓存6级以上平台
  const priority = this.cachePriority[source] || 1
  return priority >= 6
}

// 质量评估算法
assessQuality(photo) {
  let score = 50; // 基础分数

  // 分辨率评分
  const pixels = photo.width * photo.height;
  if (pixels > 20000000) score += 20; // 4K+
  else if (pixels > 8000000) score += 15; // 1080p+
  else if (pixels > 2000000) score += 10; // 720p+

  // 受欢迎程度
  if (photo.likes > 1000) score += 15;
  else if (photo.likes > 500) score += 10;
  else if (photo.likes > 100) score += 5;

  // 下载量
  if (photo.downloads > 50000) score += 10;
  else if (photo.downloads > 10000) score += 7;
  else if (photo.downloads > 1000) score += 5;

  return Math.min(100, Math.max(0, score));
}
