## 🚀 申请步骤

### 步骤1: 访问千帆平台（1分钟）

**操作**: 打开浏览器，访问以下链接

```
https://qianfan.cloud.baidu.com/
```

**预期页面**: 百度智能云千帆大模型平台首页

**登录**: 使用您的百度账号登录（与ASR服务相同的账号）

---

### 步骤2: 进入控制台（1分钟）

**操作**: 点击页面右上角的"控制台"按钮

**或直接访问**:
```
https://console.bce.baidu.com/qianfan/ais/console/applicationConsole/application
```

**预期页面**: 千帆大模型应用控制台

---

### 步骤3: 创建应用（2分钟）

#### 3.1 点击"创建应用"按钮

**位置**: 应用列表页面右上角

#### 3.2 填写应用信息

| 字段 | 填写内容 | 说明 |
|------|----------|------|
| **应用名称** | VidSlide AI | 或任意名称 |
| **应用类型** | 其他 | 从下拉菜单选择 |
| **应用描述** | 视频内容生成和质量验证系统 | 可选 |
| **接口调用方式** | API | 默认选项 |

#### 3.3 点击"确定"创建应用

**预期结果**: 应用创建成功，跳转到应用详情页

---

### 步骤4: 获取API密钥（1分钟）

**在应用详情页，您会看到**:

```
应用名称: VidSlide AI
应用ID: xxxxx
API Key: ABCDefgh1234567890...     [复制]
Secret Key: XYZabcd9876543210...   [复制]
```

**重要**:
1. 点击 **[复制]** 按钮，分别复制 `API Key` 和 `Secret Key`
2. 保存到安全的地方（待会要用）

**⚠️ 注意**:
- Secret Key 只在创建时显示一次，请妥善保存
- 如果忘记了，可以重置（但会失效旧的密钥）

---

### 步骤5: 开通服务（3分钟）⭐ 重要

#### 5.1 进入"服务管理"

**位置**: 左侧菜单 → "服务管理" → "我的服务"

**或直接访问**:
```
https://console.bce.baidu.com/qianfan/ais/console/onlineService
```

#### 5.2 开通必需的服务

**需要开通的服务**:

| 服务名称 | 用途 | 是否必需 |
|---------|------|---------|
| **ERNIE-Bot** | 基础文本聊天 | ✅ 必需 |
| **ERNIE-4.0-Turbo-128K** | 视觉理解和图片对比 | ✅ **必需** |
| ERNIE-Bot-turbo | 快速文本聊天 | ⚪ 可选 |

#### 5.3 开通方式

1. 在服务列表中找到 **ERNIE-4.0-Turbo-128K**
2. 点击"开通"或"立即使用"按钮
3. 阅读服务协议，勾选"同意"
4. 点击"确认开通"

**预期结果**:
```
✅ ERNIE-4.0-Turbo-128K 已开通
```

#### 5.4 检查配额

**免费试用额度** (新用户):
- ERNIE-Bot: 通常有数千次免费调用
- ERNIE-4.0-Turbo-128K: 通常有数百次免费调用

**查看方式**:
- 位置: 控制台 → "资源管理" → "配额管理"
- 或在服务详情页查看剩余额度

---

### 步骤6: 配置到项目（2分钟）

#### 6.1 打开终端，编辑.env文件

```bash
cd "/Users/weilei/VidSlide AI/vidslide-ai"
nano .env
```

#### 6.2 添加API密钥

**在文件末尾添加以下内容**:

```bash
# 文心一言API密钥（用于MLLM视觉验证）
WENXIN_API_KEY=你的API_Key
WENXIN_SECRET_KEY=你的Secret_Key
```

**替换说明**:
- 把 `你的API_Key` 替换为步骤4复制的 API Key
- 把 `你的Secret_Key` 替换为步骤4复制的 Secret Key

**示例** (不要用这个，用你自己的):
```bash
WENXIN_API_KEY=ABCDefgh1234567890
WENXIN_SECRET_KEY=XYZabcd9876543210
```

#### 6.3 保存并退出

- 按 `Ctrl + O` 保存
- 按 `Enter` 确认
- 按 `Ctrl + X` 退出

## ❓ 常见问题

### Q1: 步骤5找不到ERNIE-4.0-Turbo-128K服务

**可能原因**:
- 服务名称可能略有不同
- 可能在"在线服务"或"模型广场"中

**解决方法**:
1. 在服务列表中搜索 "ERNIE-4.0" 或 "Turbo"
2. 或查找"多模态"、"视觉理解"类别
3. 如果实在找不到，可以先开通 ERNIE-Bot 4.0，也支持视觉功能

### Q2: 提示"配额不足"或"余额不足"

**解决方法**:
1. **检查免费额度**: 新用户通常有免费试用额度
2. **充值**: 如果免费额度用完，需要充值（建议充¥10-20元测试）
3. **查看计费**: 控制台 → "计费管理" → "用量统计"

**费用参考** (2026年1月):
- 输入: ¥0.004 / 1000 tokens
- 输出: ¥0.008 / 1000 tokens
- 一次图片对比约 ¥0.024 元

### Q3: 验证脚本显示"视觉模型测试失败"

**可能原因**:
- ERNIE-4.0-Turbo-128K 服务未开通
- 账号权限问题

**解决方法**:
1. 返回步骤5，确认已开通服务
2. 等待5-10分钟后重试（服务开通可能有延迟）
3. 检查应用是否绑定了正确的服务

### Q4: API Key配置后仍然提示"未配置"

**检查清单**:
```bash
# 1. 检查.env文件内容
cat .env | grep WENXIN

# 应该看到:
# WENXIN_API_KEY=...
# WENXIN_SECRET_KEY=...

# 2. 检查格式是否正确
# ✅ 正确: WENXIN_API_KEY=ABCDefgh1234567890
# ❌ 错误: WENXIN_API_KEY = ABCDefgh1234567890 (有空格)
# ❌ 错误: WENXIN_API_KEY="ABCDefgh1234567890" (有引号)
```

### Q5: 测试显示"No permission to access data"

**原因**: API Key没有访问文心一言服务的权限

**解决方法**:
1. 确认API Key是从"千帆大模型平台"创建的（不是其他百度AI平台）
2. 确认已在"服务管理"中开通服务
3. 尝试重新创建一个新的应用
