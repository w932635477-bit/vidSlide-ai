自动滚动功能说明

  • 当前正在执行的步骤会自动滚动到可视区域中心
  • 正在执行的步骤有蓝色边框和脉冲动画
  • 完成的步骤显示绿色边框和淡入动画
  • 总体进度条随步骤完成而更新
  • 使用 scrollIntoView 实现平滑滚动
  • 支持多个步骤的连续执行

技术实现

  • 使用 Vue 3 的 ref 和 watch 监听步骤变化
  • 通过 nextTick 确保 DOM 更新后再滚动
  • scrollIntoView 配置 behavior: 'smooth' 实现平滑滚动
  • block: 'center' 让当前步骤居中显示
  • CSS 动画增强视觉反馈
