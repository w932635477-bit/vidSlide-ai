# 千帆视觉模型开通指引

> **预计时间**: 5分钟
> **费用**: 有免费试用额度

---

## 📋 第一步: 登录千帆控制台

访问千帆大模型平台:
```
https://console.bce.baidu.com/qianfan/overview
```

使用您创建API Key时的百度账号登录。

---

## 🎯 第二步: 开通视觉模型

### 方式1: 通过"模型广场"开通(推荐)

1. **进入模型广场**
   - 在左侧菜单选择 "模型广场"
   - 或直接访问: https://console.bce.baidu.com/qianfan/modelcenter/model/public

2. **搜索视觉模型**
   - 在搜索框输入 "ERNIE-4.0" 或 "视觉"
   - 筛选支持"图像理解"的模型

3. **推荐的视觉模型**(选一个即可):

   | 模型名称 | 特点 | 推荐度 |
   |---------|------|--------|
   | **ERNIE-4.0-8K** | 文心一言4.0,性能强大 | ⭐⭐⭐⭐⭐ |
   | qwen2-vl-7b-instruct | 通义千问视觉版,速度快 | ⭐⭐⭐⭐ |
   | deepseek-vl2 | DeepSeek视觉版 | ⭐⭐⭐ |

4. **开通模型**
   - 点击模型卡片
   - 点击"立即使用"或"开通服务"按钮
   - 阅读并同意服务协议
   - 点击"确认开通"

### 方式2: 通过"在线服务"开通

1. **进入在线服务**
   - 左侧菜单 → "应用接入" → "在线服务"
   - 或直接访问: https://console.bce.baidu.com/qianfan/ais/console/onlineService

2. **找到并开通ERNIE-4.0-8K**
   - 在服务列表中搜索 "ERNIE-4.0-8K"
   - 点击"开通"按钮
   - 确认开通

## ❓ 常见问题

### Q1: 找不到ERNIE-4.0-8K模型
**解决方法**:
- 尝试搜索 "ERNIE-4.0" 或 "文心一言4.0"
- 确认您在"模型广场"或"在线服务"页面
- 检查是否有地域限制(部分地区可能不可用)

### Q2: 提示"无权限开通"
**可能原因**:
- 账号未实名认证 → 前往账号中心完成实名认证
- 企业账号需要管理员授权
- 地域限制

### Q3: 开通后测试仍失败
**解决步骤**:
1. 等待5-10分钟,服务可能有延迟
2. 检查控制台是否显示"已开通"状态
3. 确认API Key和Secret Key正确
4. 查看详细错误信息

### Q4: 如何查看剩余配额
**查看方式**:
- 控制台 → "资源管理" → "配额管理"
- 或在模型服务页面查看"剩余额度"
