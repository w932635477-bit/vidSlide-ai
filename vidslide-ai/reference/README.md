# 理想效果视频参考（Reference Videos）

此目录用于存放质量检查的理想效果视频，用于QualityDirector进行规范性验证。

## 需要的视频

### 1. ideal_card_reference.mp4（必需）

**用途**: video-with-card场景的质量标准参考

**要求**:
- **时长**: 15-20秒
- **分辨率**: 1080x1920（抖音竖屏标准）
- **内容**:
  - 包含2-3个卡片出现的场景
  - 卡片显示简短关键词（3-5个字，如"AI技术"、"深度学习"）
  - 卡片位置正确（y坐标约1200，避开抖音底部400px安全区域）
  - 清晰展示双边框样式
  - 卡片尺寸600x300
  - 蓝色渐变背景，白色文字

**展示规范**:
- ✅ 卡片位置（避开抖音UI）
- ✅ 卡片尺寸
- ✅ 文字数量限制
- ✅ 双边框样式
- ✅ 出现时机（语音停顿时）
- ✅ 抖音安全区域遵守

### 2. ideal_multilayer_reference.mp4（可选）

**用途**: multi-layer-composition场景的质量标准参考

**要求**:
- **时长**: 10-15秒
- **分辨率**: 1080x1920
- **内容**:
  - 展示5层结构：背景 + 素材 + 遮罩 + 强调卡片 + 画中画
  - 画中画圆形边框（400x400）
  - 画中画位置（x=340, y=100）
  - 亮色强调卡片

## 验证流程

QualityDirector将使用这些视频进行两层验证：

1. **规范性验证**（对比理想视频）
   - 使用MLLM-as-a-Judge（GPT-4V或Claude 3.5 Sonnet）
   - 提取关键帧进行视觉对比
   - 检查位置、尺寸、样式、文字长度是否符合标准

2. **内容正确性验证**（对比上游数据）
   - 验证卡片显示的关键词是否匹配ContentAnalyst的输出
   - 验证时间轴是否与SceneDesigner的设计一致
   - 验证素材是否与MaterialExpert生成的内容对应
