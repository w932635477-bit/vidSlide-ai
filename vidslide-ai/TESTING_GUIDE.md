# 快速测试指南

## 🚀 立即开始测试

当前系统已配置为使用**Mock验证模式**，无需真实的MLLM API即可测试完整流程。

### 运行端到端测试

```bash
cd /Users/weilei/VidSlide\ AI/vidslide-ai

# 使用Mock验证（默认，推荐）
node test_e2e_real_video.js

# 或明确指定Mock模式
USE_MOCK_VALIDATION=true node test_e2e_real_video.js
```

### Mock验证说明

**Mock验证会做什么**:
- ✅ 使用OCR识别卡片文字
- ✅ 检查文字长度是否≤5个字符
- ✅ 验证卡片内容是否匹配期望关键词
- ⚠️ 位置和样式检查使用简化规则（假设通过）

**Mock验证的优势**:
- 🚀 快速：无需等待MLLM API调用（节省3-5秒/场景）
- 💰 免费：不消耗API配额
- 🔧 可调试：可以快速验证整体流程

**Mock验证的局限**:
- ⚠️ 不能真正对比视觉差异（位置、尺寸、样式）
- ⚠️ 只能通过OCR检查文字内容和长度
