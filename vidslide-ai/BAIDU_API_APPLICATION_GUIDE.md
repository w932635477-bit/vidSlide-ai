## 🆔 **第二步: 实名认证 (重要!)**

### **为什么需要实名认证**
百度AI开放平台要求所有开发者进行实名认证，才能申请API服务。

### **认证流程**
1. **登录后点击头像** → **"账号中心"**
2. **左侧菜单** → **"实名认证"**
3. **选择认证类型** → **"个人认证"** (推荐)

### **个人认证材料**
```
✅ 身份证正面照片
✅ 身份证反面照片
✅ 手持身份证照片 (本人手持身份证，露出脸部)
```

### **认证注意事项**
- 📸 **照片要求**: 清晰、无遮挡、完整
- ⏰ **审核时间**: 工作日1-2小时，周末可能延迟
- 💡 **备用方案**: 如果个人认证失败，可尝试企业认证

### **企业认证 (备用方案)**
如果个人认证遇到问题，可以尝试企业认证：
```
需要材料:
- 营业执照副本
- 法人身份证
- 企业邮箱
- 企业联系方式
```

```

```

### **密钥信息**
```

Secret Key: [32位字符串，如: fedcba0987654321...]
```

### **重要提醒**
- 🔒 **API Key**: 用于调用API的身份标识
- 🔒 **Secret Key**: 用于生成签名，切勿泄露
- 💾 **安全保存**: 记录在安全的地方，不要分享

## 🚨 **常见问题解决**

### **问题1: 实名认证失败**
```
原因: 照片不清晰/不完整
解决:

2. 确保身份证信息完整显示
3. 手持照片要露出脸部和身份证
```

### **问题2: API申请被拒绝**
```
原因: 应用信息填写不规范
解决:
1. 应用描述要详细说明用途
2. 选择正确的行业分类
3. 确保应用类型匹配API需求
```

### **问题3: 密钥获取失败**
```
原因: 应用状态异常
解决:
1. 检查应用是否审核通过
2. 确认服务是否成功申请
3. 刷新页面重新查看
```

### **问题4: API调用失败**
```
原因: 密钥配置错误
解决:
1. 检查API Key和Secret Key是否正确
2. 确认密钥没有多余空格
3. 查看代理服务器日志
```
