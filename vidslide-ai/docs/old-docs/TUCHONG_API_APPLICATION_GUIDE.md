## 🆔 **第二步: 实名认证 (重要!)**

### **为什么需要实名认证**
图虫创意平台要求开发者进行实名认证，才能申请API权限。

### **认证流程**
1. **登录后点击头像** → **"设置"**
2. **左侧菜单** → **"实名认证"**
3. **选择认证类型** → **"个人认证"**

### **个人认证材料**
```
✅ 真实姓名
✅ 身份证号
✅ 身份证正面照片
✅ 身份证反面照片
✅ 手持身份证照片 (本人手持身份证，露出脸部)
```

### **认证注意事项**
- 📸 **照片要求**: 清晰、无遮挡、完整
- ⏰ **审核时间**: 工作日1-2小时
- 💡 **准备充分**: 确保所有照片符合要求

### **企业认证 (备选)**
如果个人认证遇到问题，可以尝试企业认证：
```
需要材料:
- 营业执照副本

- 企业邮箱
```

## 🔑 **第四步: 获取API密钥**

### **查看API密钥**
```
开发者中心 → 您的应用 → "API密钥"
```

### **密钥信息**
```
App ID: [一串数字，如: 12345678]
App Secret: [32位字符串，如: abcdef1234567890abcdef1234567890]
Access Token: [动态生成，需要调用API获取]
```

### **重要提醒**
- 🔒 **App Secret**: 用于生成Access Token，切勿泄露
- 🔒 **安全保存**: 不要在代码中明文存储
- 💾 **环境变量**: 建议使用环境变量存储密钥

### **获取Access Token**
图虫API需要先获取Access Token：
```bash
curl -X POST "https://open.tuchong.com/oauth/token" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials&client_id=YOUR_APP_ID&client_secret=YOUR_APP_SECRET"
```

## 🚨 **常见问题解决**

### **问题1: 开发者中心找不到**
```
原因: 账号权限不足
解决:
1. 确保完成实名认证
2. 等待实名认证通过后再试
3. 刷新页面或重新登录
```

### **问题2: API权限申请被拒**
```
原因: 申请理由不充分
解决:
1. 详细描述应用场景
2. 说明非商业用途
3. 强调用户价值
4. 联系客服说明情况
```

### **问题3: Access Token获取失败**
```
原因: App ID或Secret错误
解决:
1. 检查密钥是否正确复制
2. 确认没有多余空格
3. 重新生成密钥
```

### **问题4: 搜索结果为空**
```
原因: 关键词过于具体
解决:
1. 使用更通用的关键词
2. 尝试英文关键词
3. 检查API参数格式
```
