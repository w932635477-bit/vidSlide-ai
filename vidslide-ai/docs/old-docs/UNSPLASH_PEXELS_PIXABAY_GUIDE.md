# Unsplash/Pexels/Pixabay 使用指南

## 🎯 核心机制

### 1. 自动翻译机制
VidSlide AI 会自动将中文关键词翻译为英文，然后使用英文关键词在国外平台搜索：

```
中文关键词 → 百度翻译API → 英文关键词 → Unsplash/Pexels/Pixabay搜索
```

**为什么需要翻译？**
- Unsplash/Pexels/Pixabay 主要是英文平台
- 英文关键词能获得更准确、更多样化的搜索结果
- 中文关键词在国外平台往往搜索不到相关内容

### 2. 平台选择策略
系统会根据关键词和使用情况智能选择最佳平台：

- **Unsplash**: 高质量摄影作品，适合商业使用
- **Pexels**: 免费库存照片，适合创意项目
- **Pixabay**: 多样化媒体资源，包括插画和矢量图

### 3. API额度管理
每个平台都有月使用限制：

- **Unsplash**: 5,000 次/月
- **Pexels**: 200 次/月
- **Pixabay**: 5,000 次/月

系统会自动监控使用量并在额度不足时切换到其他平台。

## 🔧 使用流程

### 自动流程
1. 用户输入中文关键词（如"绿色能源"）
2. 系统自动翻译为英文（如"green energy"）
3. 智能选择最佳平台（Unsplash/Pexels/Pixabay）
4. 执行搜索并返回结果
5. 自动缓存下载的素材

### 手动配置
可以通过调度器指定特定平台：

```javascript
// 强制使用特定平台
const results = await materialService.searchMaterials('绿色能源', {
  forcePlatform: 'unsplash', // 或 'pexels', 'pixabay'
  limit: 10
})
```

## 📊 素材库控制策略

### 800张限制设计
- **质量优先**: 精选高质量素材，避免批量低质内容
- **分类均衡**: 确保各行业领域都有代表性素材
- **去重严格**: 多层去重机制防止重复下载
- **增量优化**: 逐步完善，持续改进素材质量

### 分类配置
预设9大分类，每个分类控制在80-100张：

1. **科技类** (90张): AI, 编程, 数据科学
2. **商务类** (85张): 会议, 团队, 战略
3. **教育类** (80张): 学习, 培训, 知识
4. **设计类** (85张): UI/UX, 品牌, 平面设计
5. **生活类** (80张): 健康, 家庭, 休闲
6. **自然类** (85张): 环境, 生态, 绿色能源
7. **营销类** (85张): 数字营销, 社交媒体, 品牌
8. **金融类** (80张): 投资, 理财, 金融科技
9. **艺术类** (80张): 创意, 文化, 视觉艺术

## ⚡ 性能优化

### 缓存策略
- **智能缓存**: 根据使用频率和素材质量决定是否缓存
- **LRU淘汰**: 最近最少使用的素材优先清理
- **大小限制**: 控制本地存储不超过500MB

### 并发控制
- **并发下载**: 同时处理6个关键词
- **重试机制**: 失败自动重试，最多3次
- **超时控制**: 单个请求30秒超时

## 🔍 搜索优化

### 关键词增强
系统会自动为关键词添加相关术语：

```
"绿色能源" → "green energy", "renewable energy", "sustainable power"
```

### 结果筛选
- **质量评估**: 根据分辨率、色彩、构图评分
- **相关性排序**: 最相关的结果排在前面
- **多样性保证**: 避免相似图片重复

## 🚀 使用建议

1. **从核心关键词开始**: 先下载最常用的关键词
2. **关注质量而非数量**: 800张高质量素材比1500张低质素材更有价值
3. **定期更新**: 每个月检查新素材并补充
4. **监控使用情况**: 通过统计面板了解各平台使用情况
