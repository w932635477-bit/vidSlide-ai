## 📊 整体工作流程图

```
用户上传视频
    ↓
┌─────────────────────────────────────────────────────────────┐
│                  ProjectManager（项目经理）                   │
│                     - 制定6阶段执行计划                        │
│                     - 协调所有智能体                          │
│                     - 监控进度和质量                          │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│  阶段0: 时间轴构建（0-10%）- 串行执行 ⭐新增                   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  TimelineBuilder（时间轴构建器）                      │   │
│  │  ├─→ 步骤1: 语音识别（带精确时间戳）                  │   │
│  │  │   输入: 原视频                                    │   │
│  │  │   API: 百度ASR（词级别时间戳）                    │   │
│  │  │   输出: [                                         │   │
│  │  │     {                                            │   │
│  │  │       startTime: 0.0,                            │   │
│  │  │       endTime: 5.2,                              │   │
│  │  │       text: "AI的深度思考依赖强化学习",           │   │
│  │  │       confidence: 0.95                           │   │
│  │  │     }                                            │   │
│  │  │   ]                                              │   │
│  │  │                                                   │   │
│  │  ├─→ 步骤2: 语音停顿检测                             │   │
│  │  │   分析相邻语音段之间的停顿                        │   │
│  │  │   停顿 > 0.5秒 → 识别为自然断点                  │   │
│  │  │   输出: speechSegments（包含停顿段）              │   │
│  │  │                                                   │   │
│  │  ├─→ 步骤3: 插入点识别                               │   │
│  │  │   基于停顿时长评估适合度:                         │   │
│  │  │   - 停顿 > 0.8秒 → high（最佳插入点）            │   │
│  │  │   - 停顿 0.5-0.8秒 → medium（可用插入点）        │   │
│  │  │   - 停顿 < 0.5秒 → low（不推荐）                 │   │
│  │  │                                                   │   │
│  │  └─→ 步骤4: 生成基础时间轴                           │   │
│  │      输出: baseTimeline {                            │   │
│  │        version: '1.0',                               │   │
│  │        videoInfo: { duration, fps, resolution },    │   │
│  │        speechSegments: [...],  // 语音分段+停顿     │   │
│  │        insertionPoints: [...],  // 最佳插入时机     │   │
│  │        sceneChanges: [...]      // 场景变化（可选） │   │
│  │      }                                               │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│  阶段1: 内容理解（10-20%）- 串行执行                          │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  ContentAnalyst（内容分析师）                         │   │
│  │  ├─→ 步骤1: 基于时间轴的内容分析 ⭐更新                │   │
│  │  │   输入: baseTimeline（来自TimelineBuilder）       │   │
│  │  │   提取语音文本: speechSegments.filter(!isPause)  │   │
│  │  │                                                   │   │
│  │  ├─→ 步骤2: 文心一言深度分析                         │   │
│  │  │   输入: 完整文案文本                              │   │
│  │  │   输出: {                                         │   │
│  │  │     keywords: [                                  │   │
│  │  │       {text: "强化学习", english: "RL", category: "tech"}│   │
│  │  │     ],                                           │   │
│  │  │     viewpoints: [                                │   │
│  │  │       {text: "观点内容", importance: "high"}      │   │
│  │  │     ],                                           │   │
│  │  │     explanations: [...]                          │   │
│  │  │   }                                              │   │
│  │  │                                                   │   │
│  │  ├─→ 步骤3: 映射到时间轴 ⭐新增                       │   │
│  │  │   将观点和解释映射到精确的插入点                  │   │
│  │  │   优先选择high适合度的插入点                      │   │
│  │  │   输出: understanding（已映射到时间轴）           │   │
│  │  │   {                                              │   │
│  │  │     viewpoints: [                                │   │
│  │  │       {                                          │   │
│  │  │         text: "观点",                            │   │
│  │  │         startTime: 5.0,  // 精确时间             │   │
│  │  │         insertionPoint: {...}  // 关联的插入点   │   │
│  │  │       }                                          │   │
│  │  │     ]                                            │   │
│  │  │   }                                              │   │
│  │  │                                                   │   │
│  │  └─→ 步骤4: 质量检查                                 │   │
│  │      - 检查文案完整性                                │   │
│  │      - 检查关键词准确性                              │   │
│  │      - 检查时间轴映射正确性                          │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│  阶段2: 场景设计（20-30%）- 串行执行                          │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  SceneDesigner（场景设计师）                          │   │
│  │  ├─→ 步骤1: 生成UI时间轴 ⭐更新                       │   │
│  │  │   输入: baseTimeline + understanding（已映射）    │   │
│  │  │   基于插入点生成clips                             │   │
│  │  │                                                   │   │
│  │  │   输出: uiTimeline {                              │   │
│  │  │     version: '1.0',                               │   │
│  │  │     duration: 30,                                 │   │
│  │  │     fps: 30,                                      │   │
│  │  │     tracks: [                                     │   │
│  │  │       {id: 'track_original', name: '原视频轨道'},  │   │
│  │  │       {id: 'track_cards', name: '卡片轨道'},      │   │
│  │  │       {id: 'track_pip', name: '画中画轨道'},      │   │
│  │  │       {id: 'track_material', name: '素材轨道'}    │   │
│  │  │     ],                                            │   │
│  │  │     markers: [...]  // 插入点标记                 │   │
│  │  │   }                                               │   │
│  │  │                                                   │   │
│  │  │   每个clip包含:                                   │   │
│  │  │   - 精确的startTime和endTime                      │   │
│  │  │   - 关联的insertionPoint                          │   │
│  │  │   - 特效配置（effects）⭐新增                     │   │
│  │  │   - 关键帧动画（keyframes）                       │   │
│  │  │                                                   │   │
│  │  └─→ 步骤2: 质量检查                                 │   │
│  │      - 检查时间轴无重叠                              │   │
│  │      - 检查clips完整性                               │   │
│  │      - 检查与前端TimelineEditor兼容性                │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│  阶段3: 素材生成（30-60%）- 并行执行                          │
│                                                              │
│  ┌──────────────────┐  ┌──────────────────┐               │
│  │ MaterialExpert   │  │ VisualDesigner   │               │
│  │ （素材专家）      │  │ （视觉设计师）    │               │
│  └──────────────────┘  └──────────────────┘               │
│          │                      │                           │
│          │              ┌───────▼───────────┐               │
│          │              │ VisualEffectsService│ ⭐新增      │
│          │              │ （视觉特效服务）    │               │
│          │              └─────────────────────┘               │
│          │                                                    │
│  ┌───────▼──────────────────────────────────────────┐       │
│  │  任务1: 生成内容素材（MaterialExpert）            │       │

│  │  │   ├─→ 步骤1: 生成精准提示词                    │       │

│  │  │   │   提示词模板:                              │       │
│  │  │   │   "竖版信息图，主题：强化学习              │       │
│  │  │   │    风格：现代科技感，深色背景              │       │
│  │  │   │    内容：包含'强化学习'相关的文字说明和图示│       │
│  │  │   │    尺寸：1080x1920                         │       │
│  │  │   │    要求：信息准确，视觉清晰"               │       │
│  │  │   │                                            │       │
│  │  │   ├─→ 步骤2: 调用豆包生成图片                  │       │

│  │  │   │                                            │       │

│  │  │   │                                            │       │
│  │  │   ├─→ 步骤4: 图像识别验证（检查内容相关性）    │       │
│  │  │   │   使用文心一言图像理解                     │       │
│  │  │   │   验证: 图片内容是否与关键词相关           │       │
│  │  │   │                                            │       │
│  │  │   └─→ 步骤5: 如果验证失败，重新生成（最多3次） │       │
│  │  │                                                │       │
│  │  └─→ 输出: {                                      │       │
│  │      "强化学习": "material_1.png",                │       │
│  │      "涌现": "material_2.png"                     │       │
│  │    }                                              │       │
│  └───────────────────────────────────────────────────┘       │
│                                                              │

│  │  │   │                                            │       │
│  │  │   │   - 黄色卡片（次要观点）                   │       │
│  │  │   │     背景: 渐变黄色                         │       │
│  │  │   │     文字: 深色，加粗                       │       │
│  │  │   │     尺寸: 600x300                          │       │
│  │  │   │                                            │       │

│  │  │       调用VisualEffectsService                │       │

│  │  │       - 圆角（borderRadius: 20px）            │       │

│  │  │       - 阴影（boxShadow: 0px 4px 12px rgba）  │       │
│  │  │       - CSS样式（直接用于前端渲染）            │       │
│  │  │                                                │       │

│  │      cards: [                                     │       │
│  │        {                                          │       │

│  │              borderRadius: '20px',                │       │

│  ┌─────────────────────────────────────────────────────┐   │

## 🎯 各智能体详细职责

### 1. ContentAnalyst（内容分析师）

**核心任务**: 深度理解视频内容

```javascript
输入: 原视频文件
输出: {
  transcript: "完整文案",
  keyPoints: ["核心观点1", "核心观点2"],
  keywords: ["关键词1", "关键词2"],
  viewpoints: [
    {
      text: "AI的深度思考依赖强化学习",
      time: { start: 0, end: 5 },
      type: "main"
    }
  ],
  explanations: [
    {
      text: "强化学习通过奖励机制不断优化",
      keyword: "强化学习",
      time: { start: 5, end: 12 }
    }
  ]
}
```

**工作流程**:
1. 调用百度语音识别API → 获取文案
2. 调用文心一言API → 深度分析
3. 提取观点和解释片段
4. 标注时间轴

**核心任务**: 智能拆解场景，规划时间轴

```javascript
输入: ContentAnalyst的输出
输出: [
  {
    id: "scene_1",
    type: "video-with-card",
    startTime: 0,
    endTime: 5,
    cardText: "AI的深度思考依赖强化学习",

      background: true,
      material: true,
      mask: true,
      highlightCard: true,
      facePIP: true
    }
  },
  {
    id: "scene_3",
    type: "original",
    startTime: 12,
    endTime: 15
  }

```

**拆解规则**:
- 观点片段 → `video-with-card`
- 解释片段 → `multi-layer-composition`
- 过渡片段 → `original`
- 原视频占比 ≥ 25%

### 3. MaterialExpert（素材专家）

**核心任务**: 生成精准的内容素材

```javascript
输入: {
  keyword: "强化学习",
  context: ContentAnalyst的输出
}

输出: {
  materialPath: "material_reinforcement_learning.png",
  verified: true,
  ocrText: "强化学习 Reinforcement Learning...",
  relevanceScore: 0.95
}
```

**工作流程**:
1. 生成精准提示词
2. 调用豆包生成图片
3. OCR验证（检查关键词）
4. 图像识别验证（检查相关性）
5. 如果失败，重新生成（最多3次）

**提示词模板**:
```
竖版信息图，主题：{keyword}
风格：现代科技感，深色背景
内容：包含"{keyword}"相关的文字说明和图示
尺寸：1080x1920
要求：信息准确，视觉清晰，适合短视频展示
上下文：{context.intent}
```

---

### 4. VisualDesigner（视觉设计师）

**核心任务**: 设计卡片、背景、遮罩

```javascript
输入: SceneDesigner的输出

输出: {
  cards: [
    {
      id: "card_1",

**卡片样式**:
- **蓝色卡片**: 主要观点，渐变蓝色背景，白色文字
- **黄色卡片**: 次要观点，渐变黄色背景，深色文字
- **亮色强调卡片**: 关键词，亮色渐变，大号文字

**核心任务**: 合成最终视频

  finalVideoPath: "output_final.mp4",

**合成逻辑**:

- 根据场景类型选择合成方式
- 使用FFmpeg进行多层合成
- 添加过渡效果
- 拼接所有片段

## 🎯 关键改进点（v3.0）

### 1. 时间轴系统（TimelineBuilder）
- **问题**: 之前使用估算时间，插入时机不准确
- **解决**: 使用百度ASR精确时间戳，基于实际语音停顿识别插入点
- **效果**: 插入点误差<0.1秒，自然不打断说话

### 2. 视觉特效系统（VisualEffectsService）
- **问题**: 之前没有统一的特效管理，卡片和画中画缺少圆角、边框、阴影
- **解决**: 创建VisualEffectsService，自动为所有元素添加特效
- **效果**: 每次创建卡片/画中画时特效自动应用，视觉效果专业统一

### 3. UI兼容性
- **问题**: 后端生成的数据与前端TimelineEditor不兼容
- **解决**: SceneDesigner生成UI兼容的时间轴，包含完整的特效配置
- **效果**: 前端可以直接使用，无需转换

### 4. 数据流转优化
- **改进**: TimelineBuilder → ContentAnalyst → SceneDesigner 串行执行
- **优势**: 每个阶段都基于精确的时间轴数据，避免时间误差累积
