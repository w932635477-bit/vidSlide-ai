## 🚀 立即使用

### 1. 启动 Remotion Studio
```bash
cd remotion-templates
npm start
```
访问: http://localhost:3001

### 2. 浏览所有模板
- 左侧列表可以看到所有 27 个模板
- 点击任意模板查看预览
- 右侧可以调整参数

### 3. 导出视频
- 在 Studio 中点击 "Render" 按钮
- 选择输出格式和质量
- 等待渲染完成
