🔑 核心改进点

1. 工作逻辑优化

问题: 文心一言把"巨量ad"理解成"质量ad"

解决: 在Prompt中明确强调"必须从原文精确提取，不要改写"

关键要求： 1. 关键词提取（最重要）： - 必须从原文中精确提取，不要改写、总结或意译 - 如果原文是"巨量ad"，就提取"巨量ad"，不要改成"质量ad"或其他 - 提取3-5个核心关键词 - 提供准确的英文翻译

2. 数据流优化

问题: 使用完整观点句子作为卡片文本

解决:

  • ContentAnalyst提取关键词对象（含英文）
  • SceneDesigner匹配相关关键词
  • VisualDesigner使用关键词对象生成卡片

3. 视觉效果优化

问题: 卡片太小、位置不对、无英文

解决:

  • 尺寸增大到600x300
  • 位置改为底部居中
  • 添加英文副标题
  • 字体增大到72px

📁 修改的文件清单

  • QianfanService.js - Prompt优化和格式变更
  • SceneDesigner.js - 使用关键词对象
  • ProfessionalCardGenerator.js - 双语卡片生成

⚙️ 技术实现细节

关键词对象结构

{ "text": "巨量ad", // 中文关键词 "english": "Massive AD", // 英文翻译 "category": "platform" // 类别 }

卡片生成逻辑

// 处理关键词对象 if (typeof text === 'object' && text.text) { mainText = text.text; // 中文主标题 subText = text.english; // 英文副标题 } // 绘制中文主标题（大字） ctx.font = 'bold 72px "PingFang SC"'; ctx.fillText(mainText, width / 2, height / 2 - 30); // 绘制英文副标题（小字） ctx.font = 'normal 32px Arial'; ctx.fillText(subText, width / 2, height / 2 + 40);

卡片位置计算

// 底部居中位置 const cardWidth = 600; const cardHeight = 300; const videoWidth = 1080; const videoHeight = 1920; const bottomMargin = 100; const x = (videoWidth - cardWidth) / 2; // 水平居中: 240 const y = videoHeight - cardHeight - bottomMargin; // 底部: 1520
